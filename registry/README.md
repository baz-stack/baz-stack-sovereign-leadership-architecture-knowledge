# Registry

Machine-readable indexes. All are generated or checked by `tools/`.

| File | Purpose |
|---|---|
| `source-of-truth.yaml` | Authority order and every governing/source document with version, status, hash |
| `products.yaml` | Product and course registry (public projection) |
| `frameworks.yaml` | IP and framework registry (public projection) |
| `conflicts.yaml` | Open source conflicts, recorded not resolved |
| `decisions.yaml` | Founder decision queue (nothing approved) |
| `restricted-manifest.yaml` | What is held out of this public repository, and why |
