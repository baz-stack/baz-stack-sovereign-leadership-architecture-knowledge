# Source Hierarchy and Governance

When sources disagree, the higher one wins:

1. Current approved public canon in this repository.
2. Verified evidence (see [Evidence Library](Evidence-Library.md)).
3. Public research references ([Research Foundations](Research-Foundations.md)).
4. Approved explanatory documentation (this knowledge base, FAQs, glossary).
5. Historical material, which is labelled as historical and never overrides current canon.

Retired terms and withdrawn claims are listed in [canon/RETIRED.md](../../canon/RETIRED.md). The governing source registry is [registry/source-of-truth.yaml](../../registry/source-of-truth.yaml). Open conflicts and decisions are recorded, never resolved silently: [registry/conflicts.yaml](../../registry/conflicts.yaml), [registry/decisions.yaml](../../registry/decisions.yaml).

Protected documents (the governing canon, the ideal-client profile, product specifications, unpublished pricing, client material) are held in a separate private repository and are not published. Publishing `llms.txt` or this knowledge base does not guarantee inclusion in any AI system's training data, search results or answers.

Repository rules for contributors and agents: [GOVERNANCE.md](../../GOVERNANCE.md), [agents/RETRIEVAL_POLICY.md](../../agents/RETRIEVAL_POLICY.md).
